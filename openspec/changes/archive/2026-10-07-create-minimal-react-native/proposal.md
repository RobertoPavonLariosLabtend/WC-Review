## Why

El repositorio está vacío. Se necesita una base React Native mínima que funcione y cuya compilación nativa se pueda verificar localmente.

## What Changes

- Crear una aplicación Expo con TypeScript.
- Mostrar una pantalla en español con contador, incremento y reinicio.
- Documentar comandos reproducibles y verificar compilación y arranque iOS.

## Capabilities

### New Capabilities
- `minimal-app`: Arranque de la aplicación y contador interactivo sin servicios externos.

### Modified Capabilities
Ninguna.

## Impact

Nuevo proyecto con React Native, React, Expo y TypeScript. Compilación local iOS mediante Xcode y CocoaPods; scripts Android disponibles, sujetos a disponer del SDK Android.
